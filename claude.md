# K-Mirror

A Krishnamurti-inspired psychological inquiry companion — implemented as a single Claude Code skill.

**Usage**: `/k-mirror` in any Claude Code session.

**Skill file**: `~/.claude/skills/k-mirror.md`

**Backup**: Full original Python implementation (LangGraph + ChromaDB + SQLite) at `../K-mirror-backup.zip`

> *"Truth is a pathless land. I cannot tell you how to get there; you must find it yourself."*

## Facilitation Notes

- **The quote pool exists to diversify inquiry.** Each session should draw from multiple principles across turns — fear, desire, identity, attachment, becoming, observation, the controller, relationship, sorrow. The theme files in `wiki/` contain curated quotes organized by principle; avoid repeating the same angle (e.g. time/future). Let each turn approach the same wound from a different direction.
