# K-Mirror

A Krishnamurti-inspired psychological inquiry companion — implemented as a single Claude Code skill.

**Usage**: `/k-mirror` in any Claude Code session.

**Skill file**: `~/.claude/skills/k-mirror.md`

**Backup**: Full original Python implementation (LangGraph + ChromaDB + SQLite) at `../K-mirror-backup.zip`

> *"Truth is a pathless land. I cannot tell you how to get there; you must find it yourself."*

## Wiki Structure

The `wiki/` directory is a principle-based inquiry guide organized by theme.

**Theme files** — Each explores a core principle K taught:

- [Thought](wiki/thought.md), [Desire](wiki/desire.md), [Fear](wiki/fear.md), [Observation](wiki/observation.md)
- [Consciousness & Identity](wiki/consciousness-identity.md), [Memory & Identity](wiki/memory-identity.md)
- [Relationship](wiki/relationship.md), [Attachment](wiki/attachment.md), [Love](wiki/love.md)
- [Becoming](wiki/becoming.md), [Death & Living](wiki/death-living.md), [Sorrow](wiki/sorrow.md)
- [Controller & Controlled](wiki/controller.md), [Security & Aloneness](wiki/security-aloneness.md), [Intelligence](wiki/intelligence.md), [Seeing the False](wiki/seeing-false.md)

Each theme file contains curated quotes, cross-references to related themes, and inquiry pathways.

**Navigation Guide** — [NAVIGATION.md](wiki/NAVIGATION.md) routes inquiries to themes based on the user's question or wound (e.g., "suffering & release", "fear & security", "love & relationship").

**Transcripts Library** — [wiki/transcripts/](wiki/transcripts/) stores full talk transcripts organized by location and year, with an [INDEX](wiki/transcripts/INDEX.md) for easy reference.

## Facilitation Notes

- **The quote pool exists to diversify inquiry.** Each session should draw from multiple principles across turns — fear, desire, identity, attachment, becoming, observation, the controller, relationship, sorrow. The theme files in `wiki/` contain curated quotes organized by principle; avoid repeating the same angle (e.g. time/future). Let each turn approach the same wound from a different direction.
