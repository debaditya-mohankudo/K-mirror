# On Security & Aloneness

> "There is no help outside of ourselves. No political or religious system, or every type of guru with their systems and theories — we have had all those things before during the last millennia upon millennia."

> "To be a light to oneself means standing totally alone psychologically. The word 'alone' means all one — together, whole, not fragmented."

> "There is no security in isolation. This process of isolation is fragmentation. The search for security in isolation is the cause. If one is free of that cause there is no fragmentation."

> "The brain needs security. But at present the brain is confused. And in that confusion it says, 'I must be secure.' So it then invents a new illusion. I have dropped this illusion as I find there is no security. Then I find another illusion and I hope to find security in there."

> "There is security only in intelligence. Intelligence of that kind is supreme security."

> "I've sought security in this house — there is no security. I've sought security in my wife — there isn't any. Then I find security in a church, in a god, in a belief, in a faith. You see what is happening? You are all externalising, giving me security in things in which there is no security."

> "Is there a deep abiding security? Not in furniture, not in a house, not in my wife, or in some idea — find deeply if there is such a thing as complete security."

> "Individual can never have that security."

> "The brain to function efficiently, clearly, without any kind of confusion, must understand what is security, what is stability — a sense of firmness so that it is not wishy-washy, wobbling all over the place."

> "If one is confused, uncertain, with a thousand problems, how can the brain be secure? The brain needs extraordinary stability, the brain needs to be absolutely clear, firm, unshakeable."

> "The brain can only be stable, have complete security, when we understand the whole process of becoming."
